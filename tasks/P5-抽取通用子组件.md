## 任务 5a：ScoreBar.vue

### 要求

从 ProgressView 和 ResultView 中提取通用的分数条组件。

```vue
<script setup lang="ts">
interface Props {
  label: string
  value: number
  max?: number    // 默认 100
  color?: string  // 默认主色调
  showValue?: boolean  // 默认 true
}
</script>
```

**设计：**
- 左侧 label 文字
- 中间渐变进度条（圆角）
- 右侧数值
- 宽度自适应父容器
- 当 `value < 30` 时颜色变红，`value >= 80` 时变绿

## 任务 5b：CountdownTimer.vue

### 要求

从 Part B/C 中提取倒计时显示组件。

```vue
<script setup lang="ts">
interface Props {
  seconds: number      // 总计时长
  autoStart?: boolean  // 是否在挂载后自动开始
  warningAt?: number   // 倒数多少秒时变红，默认 5
}

interface Emits {
  timeout: []   // 倒计时结束时触发
}
</script>
```

**设计：**
- 圆形或药丸形计时器显示
- 最后 warningAt 秒数字变红 + 闪烁动画
- 触发 timeout 后显示"时间到！"
- 可配合 useTimer 使用

### 验收标准

- [ ] Props/Emits 类型完整
- [ ] 倒计时显示正确
- [ ] 最后 5 秒变红闪烁
- [ ] timeout 事件正确触发

## 任务 5c：SpeechInput.vue

### 要求

从 Part A/B/C 中提取通用的语音输入组件——一个"按钮 → 语音识别 → 填入文本框"的完整输入单元。

```vue
<script setup lang="ts">
interface Props {
  placeholder?: string  // textarea placeholder
  language?: string     // 识别语言，默认 'en-US'
}

interface Emits {
  transcript: [text: string]     // 最终识别结果
  interim: [text: string]        // 实时中间结果
}

// v-model 支持
const model = defineModel<string>()
</script>
```

**设计：**
- 左侧/上方：🎤 按钮（录音时显示红点动画）
- 底部/下方：textarea（识别结果自动填入，用户可编辑）
- 识别中时显示实时转写（interim）
- 按下 🎤 按钮开始识别，再次按下停止
- 支持 v-model 绑定

### 验收标准

- [ ] v-model 双向绑定正常
- [ ] 🎤 按钮正确切换录制/停止状态
- [ ] 识别内容自动填入 textarea
- [ ] 用户可编辑 textarea（修正识别误差）
- [ ] 在 Part A/B/C 视图中替换原手写的语音输入代码
