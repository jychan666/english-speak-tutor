## 任务 3a：抽取诊断引擎

### 要求

从 `scoring.ts` 中提取以下内容到 `diagnostics/index.ts`：

**现有代码迁移（保持行为一致）：**
- `buildDiagnostic(input: DiagnosticInput): DiagnosticReport`
- `toLevel(score: number): DiagnosticReport['overallLevel']`
- `dimensionArticleMap: Record<DiagnosticDimension, string[]>`
- `DiagnosticDimension` 类型
- `DiagnosticInput` 接口

**新功能——跨练习分析：**

```typescript
export interface TrendAnalysis {
  dimension: DiagnosticDimension
  trend: 'up' | 'down' | 'stable'
  currentScore: number
  previousScore: number
}

export interface SkillInsight {
  topWeaknesses: Array<{ dimension: DiagnosticDimension; score: number }>
  trends: TrendAnalysis[]
  overallAssessment: string
}

export function analyzeSkillTrends(
  attempts: ExamAttempt[],
  limit?: number
): SkillInsight
```

`analyzeSkillTrends` 逻辑：
1. 取最近 limit 条记录（默认 20）
2. 按时间顺序分组，前半 vs 后半对比
3. 计算每个维度的变化方向
4. 返回最弱的 3 个维度和各维度趋势

### 迁移注意事项

- `scoring.ts` 中原 `buildDiagnostic` 改为 `import` 方式引用
- 确保所有导入路径正确（使用 `@/engine/diagnostics`）
- 不改变 `scorePartA` / `scorePartB` / `scorePartC` 的返回结构

## 任务 3b：实现推荐引擎

### 要求

在 `recommend.ts` 中实现 PRD 3.3.3 节定义的 4 条规则：

```typescript
export interface Recommendation {
  recommendedArticles: string[]    // 学习文章 ID 列表
  recommendedPractice: string[]    // 练习建议列表
  reason: string                   // 推荐理由（中文，简短）
}

export interface RecommendInput {
  skillProfile: SkillProfile
  attempts: ExamAttempt[]
  examDate?: string  // 可选，用户设定考试日期
}

export function generateRecommendations(input: RecommendInput): Recommendation
```

**规则实现：**

| # | 条件 | 行为 |
|---|------|------|
| 1 | 任一维度 < 60% | 推荐该维度对应的学习文章（从维度-文章映射表中查找） |
| 2 | 同一维度连续 3 次无进步（±3 分内） | 推荐"换学习策略"，建议切换练习类型 |
| 3 | 5+ 次练习记录 | 生成"今日推荐练习"（优先薄弱题型） |
| 4 | examDate 设置且距今天 < 7 天 | 切换为"考前冲刺模式"，只推荐 Part A/B/C 各 1 篇高优先级 |

**维度-文章映射表：**
```typescript
// 使用 diagnostics/index.ts 中的 dimensionArticleMap
// 如果某维度没有对应文章，从 tips 类别随机推荐
```

**注意：**
- 多条规则同时满足时，按 4 > 1 > 3 > 2 的优先级输出
- `reason` 字段用中文描述，例如："【考前冲刺】距离考试还有 5 天，建议集中练习薄弱题型 Part C"
- 返回的 `recommendedArticles` 不超过 4 篇
