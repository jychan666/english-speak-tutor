# P1：修复语音识别连续模式

## 概述

Part A 模仿朗读需要学生在朗读长段落时不间断地录入语音，但目前 `useSpeechRecognition` composable 未启用 `continuous` 模式，朗读过程中第一次停顿后识别就会自动停止，导致转写内容不完整。

## 影响范围

| 影响 | 说明 |
|------|------|
| Part A 朗读 | 识别会在第一次停顿后中断 |
| Part C 复述 | 同样受此影响（长段输出） |
| MockExam Part A/C | 同上 |

## 修改文件

| 文件 | 操作 |
|------|------|
| `client/src/composables/useSpeechRecognition.ts` | 修改 |

## 要求

在 `createInstance()` 方法中，`instance.lang = 'en-US'` 之后增加一行：

```typescript
instance.continuous = true
```

完整的结果应如下（仅修改第 34 行附近）：

```typescript
const instance = new Ctor()
instance.lang = 'en-US'
instance.continuous = true    // ← 新增此行
instance.interimResults = true
instance.maxAlternatives = 1
```

## 验收标准

1. `useSpeechRecognition.ts` 中 `createInstance` 函数设置 `instance.continuous = true`
2. 不改变任何其他行为（start/stop/onresult/onerror/onend）
3. 原有手动输入 textarea 回退机制不受影响
4. Part A 朗读连续 30 秒以上不会中途停止识别

## 依赖

无。此任务可独立执行。
