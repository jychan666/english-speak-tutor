# P4：练习流程功能增强

## 概述

对 Part A/B/C 和 MockExam 的练习流程进行增强，集成 P2 产出的新 composable（useTimer、useSpeechSynthesis、useAudioRecorder），完善练习体验。

## 前置依赖

- 任务 P1 和 P2 已完成并合入 master
- P3 非必需，可并行

---

## 任务 4a：Part A 增强

### 修改文件

`client/src/views/PartARunView.vue`

### 要求

1. **替换定时器**：用 `useTimer` composable 替代内联的 `setInterval` / `startTimer()` / `stopTimer()` 手写代码
2. **播放示范朗读改进**：
   - 使用 `useSpeechSynthesis` 替代 `new SpeechSynthesisUtterance()` 手写
   - 播放期间按钮显示"正在播放..."
   - 播放结束后按钮恢复为"重播"
3. **朗读结束后自动评分**：
   - 在 `speech.onend` 回调中自动触发提交（代替手动点击"提交"）
   - 增加 `autoSubmitted` 状态防重复提交
   - 手动输入 + 录音两种模式仍然保留手动提交按钮
4. **录音回放**：
   - 使用 `useAudioRecorder` 录制学生朗读
   - 评分结果页显示"回放我的录音"按钮
   - 将 audio URL 存入 `examStore.currentAttempt` 的扩展字段

### 验收标准

- [ ] 无内联 `setInterval` 代码（全部使用 useTimer）
- [ ] 播放示范朗读时按钮显示 loading 状态
- [ ] 朗读停止后自动触发评分（延迟 2 秒确认识别完成）
- [ ] 录音可回放
- [ ] 手动输入模式不受影响

## 任务 4b：Part B 增强

### 修改文件

`client/src/views/PartBRunView.vue`

### 要求

1. **每题加语音输入**：
   - 每个提问/回答的 textarea 上方增加一个"🎤 语音输入"按钮
   - 点击按钮开始语音识别（独立实例），识别结果自动填入 textarea
   - 用户可编辑 textarea 中的内容修正识别误差
2. **倒计时限时**：
   - 使用 `useTimer` 的倒计时模式
   - 提问每题 20 秒倒计时
   - 回答每题 30 秒倒计时
   - 倒计时结束时自动进入下一题（当前题可继续手动编辑）
3. **UI 状态反馈**：
   - 当前激活的题目高亮边框
   - 倒计时数字在最后 5 秒变红
   - 已作答的题目左侧显示 ✅

### 验收标准

- [ ] 每题有语音输入按钮，输入后自动填入 textarea
- [ ] 倒计时功能正常，超时自动跳转
- [ ] 用户仍可手动编辑所有 textarea
- [ ] 计时最后 5 秒有视觉提醒
